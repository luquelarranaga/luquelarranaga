### 🗺️ Tracr — Mobile Geo-tracking Game
[Frontend](https://github.com/Dragan-London/Tracr-Front-end) | [Backend](https://github.com/S-Kirwan/Tracr-backend)

A group project built with React Native and Expo. Users are given a daily shape which they are challenged to recreate using only their movements, which is tracked and plotted on a line. You get a score at the end of each attempt, which is then displayed in both your personal stats page and a leaderboard.

My main contribution was figuring out the coordinate pipeline — taking raw GPS data, 
normalising it, and converting it into SVG paths that could be compared against the 
target shape to generate a score. I also built out the stats visualisation using 
Gifted Charts, so players can track their accuracy and distance over time.
