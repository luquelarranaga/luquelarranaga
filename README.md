## 🚧 Projects

### 🗺️ Tracr — Mobile Geo-tracking Game
[Frontend](https://github.com/Dragan-London/Tracr-Front-end) | [Backend](https://github.com/S-Kirwan/Tracr-backend)

A group project built with React Native and Expo. The concept: your phone tracks your 
movement via GPS, and you have to physically walk the shape of a star, or a triangle, 
or whatever the daily challenge throws at you.

My main contribution was figuring out the coordinate pipeline — taking raw GPS data, 
normalising it, and converting it into SVG paths that could be compared against the 
target shape to generate a score. I also built out the stats visualisation using 
Gifted Charts, so players can track their accuracy and distance over time. Genuinely 
one of the more unusual problems I've had to solve, and probably my favourite project 
so far.

### 📰 NC News — Full Stack Social News App
[Live site](https://nc-news-maria.netlify.app/) | [Frontend](https://github.com/luquelarranaga/nc-news-fe) | [Backend](https://github.com/luquelarranaga/back-end-nc-news)

A Reddit-style news platform where users can browse articles by topic, vote, and leave 
comments. Built across two separate codebases — a RESTful API on the backend and a 
React frontend that consumes it.

The backend is built with Node.js, Express, and PostgreSQL, with full CRUD 
functionality, error handling, and query filtering baked in. Everything was written 
test-first using Jest and Supertest. The frontend uses React with Axios for API calls, 
and was my first real experience of connecting a live backend to a UI I'd built myself 
— which, the first time it actually works end-to-end, is a pretty satisfying moment.
